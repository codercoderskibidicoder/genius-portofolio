A bit about me

I care about the little details.

A server can have loads of plugins and still feel unfinished. I like sorting out the small things that make it feel put together: permission logic, readable UI, consistent colors, and commands that do what players expect.

✓
Permissions that make sense

Clear ranks and inheritance instead of giving every group random permissions.

✓
UI that matches the server

TAB, scoreboards, prefixes, and colors should look like they belong together.

✓
Test it in-game

Check formatting and placeholders in the actual server, not just in a config file.
